## 已执行的检查

- 12 项 CPU 测试全部通过，见 `results/cpu_tests_final.log`。未安装新依赖。
- 合成特征使用真实 TS_DCM/Alpha_DC/TSM 和真实 256×196 输入尺寸。两种 shot 都完成 PS/DS 各 50 步。
- 关闭 PS+DS 后与 E0 逐位一致；全 256 通道恒等投影与原匹配一致；直接 SVD 与 Gram eig 子空间对照、直接 WSD 求和/导数与低秩/稠密 Cayley 对照均通过。
- 验证 Support 顺序不改变模板投影；修改 Query 特征不改变模板优化的目标和谱权重；模板 API 不接收 Query 标签。
- 合成数值测试中的原 DCM 参数及梯度不变。完整 CLIP/LSN/GLAC/TSM 的运行前后检查已写入 GPU 入口，仍须实际执行，不能把合成检查称为全模型验收。
- 实际读取 2400 个 Test 视频的长度/FPS。每种 shot 前 3 个 Episode 经完整原数据加载器解码与预处理，逐项核对 Manifest 视频/帧/标签及像素 SHA，再独立回放核对像素 SHA。
- 实际生成每种 shot 的全部 10000 Episode 清单，检验 24 类范围、每类 Support/Query 数量、无视频重复/交叉、帧索引范围、顺序/ID/hash。没有按类别频率或难度筛选 Episode。
- 两个历史正式 E0 checkpoint 均只读复核 SHA。没有使用 1-shot 权重代替 5-shot。
- 未修改原模型、checkpoint、配置或训练队列；没有 GPU 计算、训练或真实模型 CPU 推理。
