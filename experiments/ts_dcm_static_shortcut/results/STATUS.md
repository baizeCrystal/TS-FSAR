# Results status

No formal pixel counterfactual has been run in the Codex environment. The
repository has no approved native-resolution, per-frame foreground masks, and
the available S02 region artifact is explicitly not a pixel intervention.
Therefore this directory intentionally contains no fabricated accuracy or
bootstrap values. A campus run should place `status.json`, `query_rows.jsonl`,
and the offline summary here only after the mask review and frozen forward
complete successfully.
